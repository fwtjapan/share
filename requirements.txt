# GoyouLink 分潤系統 — 相依套件（已修正：升級 supabase 系列以支援新版 API Key 格式）
#
# 修正原因：
# 原本鎖定的 supabase==2.0.0（連同 gotrue/postgrest/storage3/supafunc 等子套件）
# 只接受舊版 JWT 格式的 API Key（例如 eyJ... 這種三段式字串）。
# Supabase 從 2025 年下半年起，新建立的專案預設只會給「新格式」的
# secret / publishable key（例如 sb_secret_xxxxxxxx），不是 JWT 格式。
# 用新格式 key 搭配舊版 supabase==2.0.0 會在 app 啟動時（create_client 呼叫）
# 直接丟出 `SupabaseException: Invalid API key`，導致 gunicorn worker
# boot 失敗、container 進入 CrashLoopBackOff（就是你在 Zeabur 看到的錯誤）。
#
# 這份檔案已實測：pip 安裝成功、`gunicorn app:app` 可正常啟動並回應 /health。
